# Scripts

This folder is for standalone helpers that are useful during robot testing but are not installed as ROS 2 package entry points.

Current script:

- `test_move_straight.py`: manual straight-line motion test utility.

Package nodes that should be launched with ROS 2 live under:

```text
ros2_ws/src/rosmasterx3_slam/rosmasterx3_slam/nodes/
```

Installed node entry points are managed in:

```text
ros2_ws/src/rosmasterx3_slam/setup.py
```
